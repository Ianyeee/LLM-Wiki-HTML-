[全局架構] 全景地圖：數據傳輸的五大站點

從物理微粒到前端畫布的端到端資料傳輸管線

  • 站點 1 & 2（感測與運算）：物理微粒經過 SPS30 轉為電氣訊號，由 ESP32 與 STM32 晶片分工處理。
  • 站點 3 & 4（打包與派發）：將數值打包為標準 JSON 托運單，透過 MQTT 協定發布至 Broker 轉運站。
  • 站點 5（視覺呈現）：瀏覽器經由 WebSocket 接收推播，動態渲染折線圖與警示指標。
💡 生活化比喻： 就像一條精密分工的「跨國高鐵生鮮物流鏈」，從產地採集到客戶桌上一氣呵成。

[感測轉換] 系統的靈敏五官：把空氣微粒翻譯成數位數字

SPS30 PM2.5 雷射散射與五步訊號轉換管道

  • 物理轉電氣：SPS30 雷射散射微粒，光電二極體產生微弱光電流。
  • 放大與 ADC：運算放大器放大微弱訊號，經由 ADC 取樣轉為 0 與 1 的數位訊號。
  • 出廠校準與通訊：內建晶片依校正參數補償溫濕度漂移，以 I2C/UART 輸出精準數值。
💡 生活化比喻： 感測器就是晶片的「眼睛與皮膚」，把人類感受得到的灰塵翻譯成二進位數字。

[雙晶片架構] 指揮官與偵察兵：STM32 與 ESP32 的雙腦默契

即時演算法控制與無線通訊協定的解耦分工

  • ESP32 前線通訊兵：負責感測器輪詢採樣、初步均值濾波，並掌管 Wi-Fi 無線通訊。
  • STM32 總指揮官：ARM Cortex-M4 強效大腦，專注於 SMC 滑動模態演算法與風門開度決策。
  • 雙晶片解耦效益：避免無線傳輸協定佔用 CPU 中斷，保障工業級即時控制零延遲。
💡 生活化比喻： STM32 坐在指揮所冷靜下達排風戰術；ESP32 在前線拿無線電偵察灰塵並快遞情報。

[格式標準化] 標準化物流單：為什麼物聯網系統首選 JSON？

傳輸效率、跨平台相容與除錯便利性的甜蜜平衡點

  • 直觀的 Key-Value 結構：以純文字記錄 "pm25": 24.5，人類除錯與晶片讀取兼得。
  • 跨平台與跨語言：ESP32 用 C、伺服器用 Python、網頁用 JavaScript，零溝通障礙。
  • 輕量與高擴充性：相較於 XML 節省 60% 以上頻寬，新增感測欄位時舊程式不崩潰。
💡 生活化比喻： 就像貼在包裹外的「黑貓托運單」，收件人不管講哪國話，看單子就一目了然。
Slide 6 / 9 📌 來源：wiki/03-mqtt-protocol.md

[通訊協定] 高效率推播：不用逐一打電話的 Pub / Sub 機制

MQTT 輕量發布訂閱架構與 Broker 訊息中轉站

  • 發布者 (Publisher)：ESP32 只管把訊息推送到特定 Topic，完全不需要知道誰在線。
  • 訊息轉運站 (Broker)：Mosquitto 伺服器負責管理連線，將訊息以毫秒級速度推播給訂閱者。
  • 極度輕量省電：固定標頭僅 2 Bytes，大幅降低微控制器連網功耗與行動頻寬花費。
💡 生活化比喻： 如同 YouTuber 上傳新影片到頻道（Topic），平台（Broker）主動向粉絲跳出推播通知。

[前端視覺化] 駕駛座的儀表板：從生硬數字到一目了然的畫面

WebSocket 長連線、JSON.parse 解析與 Chart.js 動態渲染

  • 雙向長連線：透過 MQTT over WebSockets，讓網頁無須手動按 F5 重新整理。
  • JSON.parse 與安全檢查：將文字還原為 JavaScript 物件，過濾異常跳動的雜訊值。
  • 動態圖表推移：利用 HTML5 Canvas 與 Chart.js，以 FIFO 佇列維持平滑流暢的時序趨勢線。
💡 生活化比喻： 就像超跑駕駛座前方的數位儀表板，你不需懂引擎燃油細節，看指針就能掌握車況。

[實戰沙盒] 現場實戰：當感測器讀到 PM2.5 = 45 μg/m³ 時？

端到端數據串聯全鏈路動態警報實測

  • T = 0.0s [感測]：SPS30 透過雷射光散射換算出 45 μg/m³，經 I2C 送進 ESP32。
  • T = 0.2s [傳輸]：ESP32 打包 JSON 封包，經由 Wi-Fi 發布到 MQTT Broker 主題 lab/env。
  • T = 0.4s [決策與呈現]：STM32 啟動抽風馬達 60% 轉速；網頁儀表板立刻跳出黃色警戒色塊！
💡 生活化比喻： 火警感知器一旦偵測到濃煙，警報器大響與灑水系統同時啟動的無縫聯防。

[總結與思維] 工程手帳回顧：構建穩健 IoT 系統的三大基石

邊緣分工、鬆散耦合與工程手帳思維

  • 邊緣分工 (Edge Allocation)：讓專門的晶片做專門的事，確保即時性與通訊互不干擾。
  • 鬆散耦合 (Loose Coupling)：以 MQTT 與 JSON 作為中介，各端升級維護互不影響。
  • 手帳思維 (Engineering Rigor)：詳實記錄每一條電路引腳、通訊協定與系統規則，讓系統永遠可擴充。
💡 生活化比喻： 一本好的工程手帳，不僅記錄過去的電路，更指引未來打造更強大系統的方向。
