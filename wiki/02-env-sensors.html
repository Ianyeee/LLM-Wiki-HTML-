02. 環境感測器與訊號轉換 (Sensor Conversion)

Overview 簡介： 真實世界的物理量（粉塵、溫度、濕度）皆為連續變化的類比訊號，感測器的使命是透過「偵測 ➔ 轉換電訊號 ➔ 放大/ADC ➔ 校準 ➔ 數位傳輸」五步驟，將物理現象翻譯為微控制器看得懂的數位資料。

1. 數據取得的完整五部曲 (The 5-Step Signal Pipeline)

+---------------------------------------------------------------------------------+
|                           感測訊號完整轉換流程管道                              |
|                                                                                 |
| 1. 物理現象      2. 轉換為電訊號     3. 放大與 ADC     4. 校準換算       5. 數位傳輸  |
| [空氣懸浮微粒] ──▶ [光電二極體微電流] ──▶ [運算放大器/ADC] ──▶ [內建微處理補償] ──▶ [I2C/UART] |
|                                                                                 |
+---------------------------------------------------------------------------------+
  1. 偵測物理現象：感測器探針或光學腔體與外界環境接觸（如 PM2.5 穿過雷射光束）。
  2. 轉換為電訊號：感測元件將微小物理變化轉為微弱電壓差或微安培級光電流。
  3. 放大與類比轉數位 (ADC)：經由運算放大器放大，ADC 以固定採樣頻率轉為離散二進位碼。
  4. 校準與換算：微處理器依原廠校正參數考量溫濕度漂移，換算為標準單位（μg/m³ 或 °C）。
  5. 數位通訊傳輸：透過 I2C 匯流排或 UART 序列埠，封裝成暫存器字組傳送給主控 MCU。

2. 代表性感測元件特點

Sensirion SPS30 (光學 PM2.5)

雷射散射原理（Laser Scattering）。內建清潔微型風扇引導氣流，微處理器自動區分 PM1.0/2.5/4.0/10，抗積灰自我清潔。

Sensirion SHT20 (溫濕度)

電容式濕度元件與能隙式溫度元件。以標準 I2C 介面輸出，具備 CRC 校驗碼保護，抗電磁干擾能力優異。

3. 典型接線對應表 (Pinout Mapping)

感測器引腳 ESP32 接腳 訊號型態 功能說明
SPS30 Pin 1 (VDD) 5V / VIN Power 供電電壓 (5V DC 驅動風扇與雷射)
SPS30 Pin 2 (RX) GPIO 17 (TX2) UART Input ESP32 發送測量指令與清潔命令
SPS30 Pin 3 (TX) GPIO 16 (RX2) UART Output SPS30 回傳 PM2.5 測量數據封包
SHT20 SDA GPIO 21 I2C Data 雙向數據傳輸線 (需 4.7kΩ 上拉電阻)
SHT20 SCL GPIO 22 I2C Clock I2C 時脈訊號線 (標準 100 kHz)

4. 新手生活化比喻 (Novice Analogy)

💡 系統的「靈敏五官與翻譯官」： 感測器就像是整個物聯網設備的「眼睛、鼻子與皮膚」―― 人類的皮膚感受到冷熱、鼻子聞到煙霧，神經系統會把它轉成大腦的神經電脈衝；感測器也是如此，它把空氣中肉眼看不到的懸浮顆粒，透過光線折射翻譯成精確的「數字刻度」，讓只懂二進位數字的單晶片大腦能夠洞察外界環境的微小變化。
