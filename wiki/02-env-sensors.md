## 1. 核心概念 (Core Concepts)

在真實世界中，物理環境如空氣中的粉塵濃度、溫度冷熱、濕度高低等，屬於連續變化的**類比現象（Analog Phenomena）**。然而，微控制器的大腦只能運算離散的二進位數位資料（`0` 與 `1`）。

**感測器（Sensor）** 的核心使命，就是扮演真實世界與微處理晶片之間的「數位轉譯橋樑」，將物理量轉化為晶片看得懂的精確數值。

---

## 2. 數據取得的完整五部曲 (The 5-Step Signal Pipeline)

一個完整的感測訊號轉換管道，依序包含以下 5 個嚴謹步驟：

```
+---------------------------------------------------------------------------------+
|                           感測訊號完整轉換流程管道                              |
|                                                                                 |
| 1. 物理現象      2. 轉換為電訊號     3. 放大與 ADC     4. 校準換算       5. 數位傳輸  |
| [空氣懸浮微粒] ──▶ [光電二極體微電流] ──▶ [運算放大器/ADC] ──▶ [內建微處理補償] ──▶ [I2C/UART] |
|                                                                                 |
+---------------------------------------------------------------------------------+
```

1. **偵測物理現象 (Physical Phenomenon Detection)**：
   感測器探針或光學腔體與外界環境接觸（例如空氣中的 PM2.5 顆粒穿過光學通道，或是高分子薄膜吸收水氣）。
2. **轉換為電訊號 (Transduction to Electrical Signal)**：
   感測元件將微小的物理變化轉化為微弱的電壓差、電流或阻抗變化（例如光散射產生的微安培級光電流）。
3. **放大與類比轉數位 (Amplification & ADC)**：
   微弱電訊號經由運算放大器（Op-Amp）放大後，由**類比轉數位轉換器（ADC, Analog-to-Digital Converter）** 以固定採樣頻率將連續波形切片取樣，轉換成 10-bit 或 12-bit 的離散數位碼。
4. **校準與換算 (Calibration & Curve Fitting)**：
   晶片依據出廠時燒錄於 EEPROM 內的校正曲線，考量溫度與濕度漂移補償係數，將數位碼換算為標準工程單位（例如 $\mu g/m^3$ 或 $^\circ C$）。
5. **數位通訊傳輸 (Digital Bus Transmission)**：
   整理後的數值經由工業標準介面（如 **I2C 匯流排** 或 **UART 序列埠**），封裝成暫存器字組傳送給主控 MCU。

## 3. 本專案代表性感測元件

### 3.1 Sensirion SPS30（光學 PM2.5 微粒感測器）
- **測量原理**：雷射散射原理（Laser Scattering）。內建微型風扇引導氣流通過雷射光束，顆粒物散射光線至光電二極體。
- **進階特點**：感測器內部自帶微處理器，能自動區分 PM1.0、PM2.5、PM4.0 與 PM10，並內建抗積灰自我清潔演算法。
- **通訊介面**：支援 UART (115200 bps) 與 I2C 雙介面，輸出經過校正的質量濃度值（$\mu g/m^3$）。

### 3.2 Sensirion SHT20（數位式溫濕度感測器）
- **測量原理**：利用電容式濕度感測元件與能隙式溫度感測元件。
- **通訊介面**：標準 I2C 介面，具備 CRC 校驗碼保護，確保傳輸過程不因電磁雜訊造成位元翻轉錯誤。

## 4. 典型接線對應表 (Pinout Mapping)

| 感測器引腳 | ESP32 接腳 | 訊號型態 | 功能說明 |
| :--- | :--- | :--- | :--- |
| **SPS30 Pin 1 (VDD)** | 5V / VIN | Power | 供電電壓 (5V DC 驅動風扇與雷射) |
| **SPS30 Pin 2 (RX)** | GPIO 17 (TX2) | UART Input | ESP32 發送測量指令與清潔命令 |
| **SPS30 Pin 3 (TX)** | GPIO 16 (RX2) | UART Output | SPS30 回傳 PM2.5 測量數據封包 |
| **SPS30 Pin 5 (GND)** | GND | Ground | 系統共同參考接地 |
| **SHT20 SDA** | GPIO 21 | I2C Data | 雙向數據傳輸線 (需 4.7kΩ 上拉電阻) |
| **SHT20 SCL** | GPIO 22 | I2C Clock | I2C 時脈訊號線 (標準 100 kHz) |

## 5. 新手生活化比喻 (Novice Analogy)

> 💡 **系統的「靈敏五官與翻譯官」**：  
> 感測器就像是整個物聯網設備的「眼睛、鼻子與皮膚」：  
> 人類的皮膚感受到冷熱、鼻子聞到煙霧，神經系統會把它轉成大腦的神經電脈衝；感測器也是如此，它把空氣中肉眼看不到的懸浮顆粒，透過光線折射翻譯成精確的「數字刻度」，讓只懂二進位數字的單晶片大腦能夠洞察外界環境的微小變化。
