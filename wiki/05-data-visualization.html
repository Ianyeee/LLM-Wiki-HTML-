05. 資料視覺化與儀表板實作 (Data Visualization)

Overview 簡介： 資料視覺化是物聯網的「最後一哩路」，將時序數值矩陣透過圖形化介面轉化為直觀視覺資訊，使人機協同與即時決策更敏捷。

1. 數據到畫面的三大轉換步驟

+-------------------------------------------------------------------------------+
|                       前端即時視覺化處理流程管道                              |
|                                                                               |
|  [步驟 1: 傳輸與接收]       [步驟 2: 資料解析與過濾]        [步驟 3: 動態渲染圖表]    |
|   MQTT over WebSockets ──▶  JSON.parse(message)   ──▶ Chart.js Canvas Update  |
|   (持續監聽 Topic 訊息)       (提取數值、時間戳與狀態)      (折線推移、顏色警戒更新)  |
+-------------------------------------------------------------------------------+

Step 1. 長連線接收

MQTT over WebSockets 保持單一雙向通道，避免重複建立連線。

Step 2. 解析與清洗

JSON.parse() 還原物件，並驗證 PM2.5 數值是否在合理物理區間。

Step 3. FIFO 佇列渲染

Chart.js 畫布保留最新 20 筆紀錄，先進先出推移更新平滑折線。

2. 前端實作範例 (HTML5 Canvas + Chart.js)

// 當 MQTT 收到新封包時更新圖表
function onSensorMessage(newPm25, timeString) {
  if (pm25Chart.data.labels.length >= 20) {
    pm25Chart.data.labels.shift();
    pm25Chart.data.datasets[0].data.shift();
  }
  pm25Chart.data.labels.push(timeString);
  pm25Chart.data.datasets[0].data.push(newPm25);
  pm25Chart.update();
}

3. 新手生活化比喻 (Novice Analogy)

💡 就像超跑的「全數位多功能儀表板」： 當你開車在高速公路上奔馳時，引擎每秒燃燒多少滴汽油、渦輪增壓閥的電壓是幾毫伏特，這些複雜的內部電子訊號都不需要你分心理解。儀表板把底層錯綜複雜的訊號，直接化為「時速表上的數字」以及「胎壓異常時亮起的紅色警示燈」。你只要輕瞄一眼，立刻知道目前的車況安不安全！
