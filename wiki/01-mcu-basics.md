## 1. 核心概念 (Core Concepts)

**MCU（Microcontroller Unit，微控制器）**，常被稱為「單晶片」，是一種將微處理器核心（CPU）、記憶體（RAM / Flash ROM）以及多種周邊輸入輸出介面（GPIO、Timers、ADC、I2C、SPI、UART 等）整合在單一積體電路晶片上的微型電腦系統。

與一般的個人電腦處理器（如 Intel Core 或 AMD Ryzen）不同，微控制器的設計目標不是為了追求極致的高速多工運算，而是為了在**低功耗、微型體積、高穩定性與高即時性（Real-time）**的要求下，精準執行特定的硬體監控與控制任務。

---

## 2. 本案例架構中的協同分工 (Dual-MCU Architecture)

在智慧空氣品質監測與自動通風控制系統中，單一 MCU 往往難以兼顧「高頻即時演算法運算」與「無線網路封包收發」。因此，本專案採用 **STM32 + ESP32 雙微控制器協同架構**：

```
+-------------------------------------------------------------+
|                     系統運作架構                            |
|                                                             |
|   [ SPS30 / SHT20 ]                                         |
|          │ (I2C/UART)                                       |
|          ▼                                                  |
|   [ ESP32 通訊與數據前哨 ] ──(UART 原始封包)──▶ [ STM32 主控中樞 ]  |
|          │                                     │            |
|          ▼ (Wi-Fi / MQTT)                      ▼ (PWM / Relay)
|     雲端 / 網頁看板                      抽風馬達 / 警報閥門  |
+-------------------------------------------------------------+
```

### 2.1 STM32：系統主軸與決策大腦 (System Core & Decision Engine)
- **硬體特點**：基於 ARM Cortex-M 核心，擁有極強的硬體中斷反應速度、高階計時器（TIM PWM）與穩定的工業級抗干擾能力。
- **本專案角色**：擔任**核心處理中樞與模型決策大腦**。負責運行滑動模態控制（SMC）、模糊控制（Fuzzy Logic）等演算法，計算受控環境的通風風門開度，並即時調節致動器與安全保護機制。

### 2.2 ESP32：感測前線與無線通訊助手 (Sensor Acquisition & Wireless Bridge)
- **硬體特點**：內建 Wi-Fi (802.11 b/g/n) 與藍牙 BLE 雙模通訊模組，具備雙核心 Xtensa 處理器。
- **本專案角色**：擔任**前線數據蒐集站與通訊閘道**。負責週期性向 PM2.5 感測器（SPS30）與溫濕度感測器讀取數據、執行初步的數位濾波（Moving Average Filter），並將乾淨的環境數據透過 MQTT 傳輸至外部網路。

## 3. 具體規格與技術參數比較

| 比較項目 | STM32F401 / F411 系列 | ESP32-WROOM-32 系列 |
| :--- | :--- | :--- |
| **CPU 核心架構** | ARM 32-bit Cortex-M4 (含 FPU) | Dual-core Xtensa 32-bit LX6 |
| **時脈速度** | 84 MHz ~ 100 MHz | 高達 240 MHz |
| **無線通訊支援** | 無（需外接模組） | 內建 2.4 GHz Wi-Fi & Bluetooth 4.2 / BLE |
| **硬體即時中斷** | 極快且確定性高（適合硬體閉迴路控制） | 易受 Wi-Fi 協定棧任務搶佔中斷影響 |
| **本案配置任務** | 演算法運算、PWM 輸出、安全連鎖閥 | 感測器輪詢、JSON 封包打包、MQTT 傳送 |

## 4. 新手生活化比喻 (Novice Analogy)

> 💡 **指揮官與偵察兵的默契搭檔**：  
> - **STM32 就像「作戰司令部的總指揮官」**：不親自跑去前線看灰塵，而是坐在辦公室裡緊盯全局。他專注於分析情報、運行複雜的戰術演算法，並隨時決定排風機應該開幾趴轉速。  
> - **ESP32 則是「前線偵察兵兼通訊特派員」**：身上背著無線電（Wi-Fi），拿著望遠鏡（感測器）在空氣品質第一線巡邏。他把量到的髒空氣數值拍電報回傳給指揮官，同時向總部雲端發布即時快訊。
