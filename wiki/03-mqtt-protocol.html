03. MQTT 物聯網通訊協定 (MQTT Pub/Sub)

Overview 簡介： MQTT 是一種專為物聯網量身打造的極輕量發布/訂閱通訊協定，固定標頭僅需 2 Bytes，藉由 Broker 中轉訊息，徹底解耦硬體端與接收端。

1. 發布與訂閱（Pub/Sub）架構

MQTT 打破了傳統 HTTP 一對一連線的依賴，透過發布者、代理伺服器（Broker）與訂閱者三者解耦運作： 

+-------------------------------------------------------------------------+
|                        MQTT 發布與訂閱架構圖                            |
|                                                                         |
|  [發布者 Publisher]                                                     |
|    ESP32 感測節點 ──▶ 發送至 Topic: "lab/roomA/env" ──┐                 |
|                                                      ▼                  |
|                                            +------------------+         |
|                                            |   MQTT Broker    |         |
|                                            | (Mosquitto/EMQX) |         |
|                                            +------------------+         |
|                                                      │                  |
|               ┌──────────────────────────────────────┴───────────────┐  |
|               ▼                                                      ▼  |
|      [訂閱者 Subscriber 1]                                 [訂閱者 Subscriber 2] |
|       前端網頁 (Web Dashboard)                                Raspberry Pi 閘道器 |
|   (訂閱 "lab/+/env"，即時畫圖)                             (訂閱 "lab/#"，存資料庫) |
+-------------------------------------------------------------------------+

Publisher 發布者

ESP32 推送訊息給指定 Topic，完全無需在乎誰在接收。

Broker 訊息中轉站

Mosquitto 維護連線，精準分發訊息給有訂閱該主題的客戶端。

Subscriber 訂閱者

瀏覽器登記主題，一旦有新資料即刻收到被動推播。

2. QoS 服務品質等級比較

QoS 等級 運作機制 頻寬負擔 適用情境
QoS 0 (最多送達一次) 射後不理，無 ACK 確認 最低 (標頭小) 高頻感測數據 (如每秒 PM2.5 採樣)
QoS 1 (至少送達一次) 需 PubAck 回應，超時重發 中等 關鍵警報與閥門狀態通知
QoS 2 (剛好送達一次) 四次交握確認，絕不重複 最高 工業精密機台啟動、金融交易

3. 新手生活化比喻 (Novice Analogy)

💡 就像 YouTube 頻道與開啟小鈴鐺：

發布者（Publisher = YouTuber）：創作者拍好影片後，直接上傳到自己的頻道（Topic）。他不用逐一打電話通知 50 萬名粉絲「我發片囉！」。

Broker（YouTube 伺服器平台）：平台負責維護整個頻道的內容庫與龐大的追隨者名單。

訂閱者（Subscriber = 開啟小鈴鐺的觀眾）：你只要按下訂閱某頻道，一旦有新影片發布，平台伺服器就會「主動跳出推播通知」送到你的手機螢幕上。
