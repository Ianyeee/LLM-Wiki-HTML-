滑模控制 (SMC) 與自適應 模糊 PID 馬達伺服實作

✦ Overview

本頁面說明如何在 STM32 微控制器上實作滑模控制（SMC）結合模糊推理（Fuzzy Logic），透過動態調節控制增益與飽和函數邊界層，實現兼具抗負載擾動與無抖振（Chattering-free）的精準馬達位置伺服控制。

✦

Hardware / Software Requirements

  • ✔ 微控制器主控板：STM32F407VET6 開發板 (ARM Cortex-M4，具 168MHz 主頻與硬體 FPU 浮點運算器)
  • ✔ 伺服受控馬達：帶 500 線 AB 相增量式光學編碼器之直流減速馬達 (12V)
  • ✔ 功率驅動模組：TB6612FNG 雙通道 H 橋馬達驅動模組 (MOSFET 低發熱架構)
  • ✔ 外部直流電源：12V 5A 直流可調穩壓電源供應器 (供馬達動力使用)
  • ✔ 開發環境與編譯鏈：STM32CubeIDE (v1.14.0 以上)、GNU Arm Embedded Toolchain
  • ✔ 演算法驗證工具：MATLAB / Simulink (Fuzzy Logic Designer 模糊規則庫推導)

Code Implementation (C 語言實作)

以下程式碼展示於定時中斷（1 kHz 控制迴路）中執行的滑模控制器。包含滑模面切換函式、飽和邊界層消除抖振（Chattering Suppression），以及模糊規則調諧切換增益：

smc_fuzzy_controller.c
STM32 HAL / C99 
#include "main.h"
#include <math.h>

/* 1. 滑模控制 (SMC) 參數結構體定義 */
typedef struct {
    float target_pos;      // 目標位置 (脈衝數或弧度)
    float current_pos;     // 當前編碼器回授位置
    float error;           // 位置誤差 e = target - current
    float prev_error;      // 上一次取樣誤差
    float error_dot;       // 誤差變化率 de/dt
    
    float c_param;         // 滑模面斜率參數 (c > 0)
    float s_surface;       // 滑模面 s = c * e + de
    float boundary_layer;  // 邊界層厚度 phi (飽和函數，消除抖振)
    
    float k_switch;        // 切換控制增益 (由模糊推論動態調節)
    float k_eq;            // 等效控制項增益
    float output_pwm;      // 控制輸出 (-1000.0f ~ +1000.0f)
} SMC_Controller_t;

static SMC_Controller_t motor_smc = {
    .c_param = 15.0f,
    .boundary_layer = 1.2f,
    .k_switch = 250.0f,
    .k_eq = 0.85f
};

/* 2. 飽和函數 sat(s / phi)：取代傳統符號函數 sgn(s) 以消除高頻抖振 */
static float Saturation_Function(float s, float phi) {
    if (phi <= 0.0001f) phi = 0.0001f;
    float ratio = s / phi;
    if (ratio > 1.0f) return 1.0f;
    if (ratio < -1.0f) return -1.0f;
    return ratio; // 邊界層內線性連續過渡
}

/* 3. 簡易單變數模糊推理：依據滑模面距離動態調整切換增益 K_switch */
static float Fuzzy_Tune_Gain(float abs_s) {
    // 遠離滑模面時加大增益確保快速收斂；接近滑模面時降低增益以防震盪
    if (abs_s > 10.0f) {
        return 380.0f; // Big: 加強強健驅動
    } else if (abs_s > 3.0f) {
        return 220.0f; // Medium: 均衡滑動
    } else {
        return 90.0f;  // Small: 柔順進入穩態
    }
}

/* 4. 1kHz 定時中斷呼叫核心控制器 (取樣週期 dt = 0.001s) */
void SMC_Controller_Update(float feedback_position, float target_position) {
    const float dt = 0.001f;
    
    // 計算誤差與誤差微分 (可視需求加入低通濾波)
    motor_smc.target_pos = target_position;
    motor_smc.current_pos = feedback_position;
    motor_smc.error = motor_smc.target_pos - motor_smc.current_pos;
    motor_smc.error_dot = (motor_smc.error - motor_smc.prev_error) / dt;
    motor_smc.prev_error = motor_smc.error;
    
    // 計算滑模面方程式：s = c * e + de
    motor_smc.s_surface = (motor_smc.c_param * motor_smc.error) + motor_smc.error_dot;
    
    // 模糊自適應調整切換項強度
    motor_smc.k_switch = Fuzzy_Tune_Gain(fabsf(motor_smc.s_surface));
    
    // 計算控制律：u = u_eq (等效控制) + u_sw (邊界層切換控制)
    float u_eq = motor_smc.k_eq * (motor_smc.c_param * motor_smc.error_dot);
    float u_sw = motor_smc.k_switch * Saturation_Function(motor_smc.s_surface, motor_smc.boundary_layer);
    
    float total_u = u_eq + u_sw;
    
    // 飽和輸出限幅 (-1000 ~ +1000 對應硬體 PWM 比較值)
    if (total_u > 1000.0f) total_u = 1000.0f;
    if (total_u < -1000.0f) total_u = -1000.0f;
    motor_smc.output_pwm = total_u;
    
    // 5. 驅動硬體輸出 (正反轉方向與 PWM 暫存器寫入)
    if (motor_smc.output_pwm >= 0) {
        HAL_GPIO_WritePin(GPIOC, GPIO_PIN_6, GPIO_PIN_SET);
        HAL_GPIO_WritePin(GPIOC, GPIO_PIN_7, GPIO_PIN_RESET);
        __HAL_TIM_SET_COMPARE(&htim1, TIM_CHANNEL_1, (uint32_t)motor_smc.output_pwm);
    } else {
        HAL_GPIO_WritePin(GPIOC, GPIO_PIN_6, GPIO_PIN_RESET);
        HAL_GPIO_WritePin(GPIOC, GPIO_PIN_7, GPIO_PIN_SET);
        __HAL_TIM_SET_COMPARE(&htim1, TIM_CHANNEL_1, (uint32_t)(-motor_smc.output_pwm));
    }
}

控制手帳小叮嚀：

1. 邊界層厚度 $\Phi$ (phi)：若設得過小，系統會接近理想符號函數 $sgn(s)$ 產生高頻抖振（馬達發出尖銳蜂鳴聲）；若設得過大，穩態靜態誤差會增加。實務上建議從 $1.0 \sim 2.0$ 開始微調。

2. 編碼器微分雜訊：在計算 $de/dt$ 時，低速下可能因離散量化產生脈衝雜訊，可在輸入前加上一階低通濾波器（一階慣性環節），使滑模面計算更平穩。
