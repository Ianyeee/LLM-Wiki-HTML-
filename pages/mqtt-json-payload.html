使用 MQTT.js 傳送 JSON 格式感測器數據

✦ Overview

本頁面說明如何在邊緣端運算節點（如 Raspberry Pi 5）上使用 MQTT.js 客戶端套件，將 SHT20 感測器採集的溫濕度數據封裝成標準 JSON 格式發布至 MQTT Broker。

✦

Hardware / Software Requirements

  • ✔ 邊緣硬體節點：Raspberry Pi 5 (或任一安裝 Node.js 之 Linux / macOS / Windows 邊緣裝置)
  • ✔ 感測器模組：Sensirion SHT20 數位溫濕度感測器 (I2C 介面)
  • ✔ 線材：4 條母對母杜邦線 (VCC, GND, SDA, SCL)
  • ✔ 執行環境：Node.js (建議版本 v18.0.0 LTS 以上)
  • ✔ 核心相依套件：MQTT.js (npm install mqtt)
  • ✔ MQTT 訊息代理站 (Broker)：本機 Mosquitto 或公開測試伺服器 (mqtt://broker.emqx.io:1883)
✦

Wiring Diagram (接線對應)

Raspberry Pi 5 40-Pin 擴充排針與 SHT20 I2C 溫濕度感測器的硬體實體接線對應：

MCU Pin (Raspberry Pi 5) Sensor Pin (SHT20) 訊號類型 功能說明
Pin 1 (3.3V Power) VCC Power 提供 3.3V 電源正極供電
Pin 6 (Ground) GND Ground 模組接地迴路 (GND)
Pin 3 (GPIO 2 / I2C1_SDA) SDA Data I2C 串列資料雙向傳輸線
Pin 5 (GPIO 3 / I2C1_SCL) SCL Clock I2C 串列時脈同步線
✦

Code Implementation

以下程式碼展示如何使用 MQTT.js 建立長連線，採集 SHT20 數值並以 JSON.stringify() 序列化後發送至 Broker：

publisher.js
Serial Node.js 
const mqtt = require('mqtt');

// 1. MQTT Broker 連線配置
const BROKER_URL = 'mqtt://broker.emqx.io:1883';
const TOPIC_TELEMETRY = 'sensors/rpi5-node-01/telemetry';

const clientOptions = {
  clientId: `mqttjs_publisher_${Math.random().toString(16).substring(2, 8)}`,
  clean: true,
  connectTimeout: 4000,
  reconnectPeriod: 2000
};

// 2. 建立客戶端連線
const client = mqtt.connect(BROKER_URL, clientOptions);

client.on('connect', () => {
  console.log(`[MQTT] 成功連線至 Broker: ${BROKER_URL}`);
  console.log(`[MQTT] 目標發布主題 (Topic): ${TOPIC_TELEMETRY}`);

  // 連線成功後，啟動定時發布任務 (每 5 秒傳送一次)
  setInterval(() => {
    publishSensorData();
  }, 5000);
});

client.on('error', (err) => {
  console.error('[MQTT] 連線異常:', err.message);
});

client.on('offline', () => {
  console.warn('[MQTT] 客戶端離線，等待自動重新連線...');
});

// 3. 採集與格式化感測器數據 (封裝為 JSON 物件)
function readSensorPayload() {
  // [請在此處補上硬體感測器讀取邏輯或 I2C Driver]
  // 此處使用模擬讀值作為展示範例
  const temperature = parseFloat((24.0 + Math.random() * 3.0).toFixed(2));
  const humidity = parseFloat((55.0 + Math.random() * 8.0).toFixed(2));

  return {
    deviceId: 'rpi5-node-01',
    sensorType: 'SHT20',
    timestamp: new Date().toISOString(),
    metrics: {
      temperature: temperature,
      temperatureUnit: 'Celsius',
      humidity: humidity,
      humidityUnit: 'Percent'
    },
    status: 'HEALTHY'
  };
}

// 4. 發布 JSON Payload 至 MQTT Broker
function publishSensorData() {
  const payloadObject = readSensorPayload();
  const payloadString = JSON.stringify(payloadObject);

  const publishOptions = {
    qos: 1,       // 至少送達一次 (At least once)
    retain: false // 不保留最後一筆訊息於 Broker
  };

  client.publish(TOPIC_TELEMETRY, payloadString, publishOptions, (error) => {
    if (error) {
      console.error('[MQTT] 訊息發布失敗:', error);
    } else {
      console.log(`[MQTT] 數據發布成功 (QoS 1) -> ${payloadString}`);
    }
  });
}

// 5. 處理優雅關閉 (Graceful Shutdown)
process.on('SIGINT', () => {
  console.log('\n[MQTT] 收到中斷信號，正在中斷連線...');
  client.end(false, () => {
    console.log('[MQTT] 連線已安全關閉。');
    process.exit(0);
  });
});
💡
工程手帳筆記：

1. 發布前請務必使用 JSON.stringify() 序列化，MQTT 傳輸本質為二進位 Payload 或字串。

2. 正式環境中請將 Broker 金鑰與憑證放入 .env 環境變數，勿直接寫死在程式碼中。
